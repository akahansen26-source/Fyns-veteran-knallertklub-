# Fyns Veteranknallert Klub

Hjemmeside for Fyns Veteranknallert Klub (stiftet 1984).

## Stack
- Next.js (App Router)
- Tailwind CSS
- Neon Postgres
- Vercel

## Opsætning
1. Opret database på [Neon](https://console.neon.tech)
2. Tilføj `DATABASE_URL` som environment variable i Vercel
3. Sæt `ADMIN_PASSWORD` i Vercel
4. Deploy via Vercel (import dette repo)

## Admin
Gå til `/admin` og log ind med ADMIN_PASSWORD.
